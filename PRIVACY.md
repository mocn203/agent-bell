# 🔒 PRIVACY POLICY — AGENT-BELL

> **Effective Date**: October 24, 2026  
> **Version**: 2.0.0  
> **Philosophy**: Zero-Telemetry, Local-First, Developer-Owned Security  

---

## 1. Core Privacy Commitments

`agent-bell` is engineered from the ground up for software developers, autonomous AI agents, and enterprise privacy:

1. **Zero Tracking or Telemetry**: `agent-bell` collects **0** analytics events, **0** device identifiers, and **0** user behavior telemetry. We operate no telemetry servers or logging endpoints.
2. **100% User-Owned Infrastructure**: The relay Worker and KV storage run directly inside **your personal Cloudflare account**. No code diffs, logs, or notifications ever transit through any third-party or centralized `agent-bell` server.
3. **Local-First Execution**: The background runner runs strictly on your local machine (`localhost`). It exposes **0 public ports** and performs only authenticated outbound HTTPS requests to your own worker.
4. **Zero Runtime Dependencies**: The core runner, CLI, and client libraries have **0 third-party npm dependencies**, eliminating software supply chain attacks and tracking backdoors.

```
│  • Regex Sanitization  │                                     │ • Secret Scrubber      │
└────────────────────────┘                                     └───────────┬────────────┘
                                                                           │
                                            Push via TLS 1.3               ▼
                                                               ┌────────────────────────┐
                                                               │ TELEGRAM / DISCORD /   │
                                                               │ SLACK CHANNELS (YOURS) │
                                                               └────────────────────────┘
```

### 2.1 What Data Leaves Your Machine?
Only the minimal data required to render notification alerts and status messages is transmitted to your personal Cloudflare Worker:
- **Task Title & Summary**: The short descriptive message generated by your agent or CLI wrapper.
- **Git Diff Statistics**: Aggregated shortstat (`+45/-12`) and modified file paths.
- **Workspace Name**: The name or directory label configured in your local `config.json`.
- **Duration & Exit Code**: Wall-clock execution time and process termination exit code.

### 2.2 What Data Never Leaves Your Machine?
- Full file contents or proprietary codebases.
- Local environment variables and `.env` secrets.
- SSH keys, GPG keys, and local credentials.
- Full git commit logs or uncommitted proprietary intellectual property.

## 3. Automated Secret & Credential Scrubbing

Both the local client (`lib/git.js`, `clients/node/notifier.js`) and the Cloudflare Edge Worker (`worker/src/index.js`) feature automated, redundant **Regex Secret Scrubbers**. Before any payload is transmitted over the wire or posted to chat platforms, the following patterns are automatically redacted:

| Credential Type | Scrubbing Pattern | Redaction Replacement |
| :--- | :--- | :--- |
| OpenAI / Groq / Anthropic Keys | `sk-[a-zA-Z0-9_\-]{20,}` | `[REDACTED_API_KEY]` |
| GitHub Personal Access Tokens | `ghp_[a-zA-Z0-9]{36}` | `[REDACTED_PAT]` |
| GitHub Fine-Grained PATs | `github_pat_[a-zA-Z0-9_]{50,}` | `[REDACTED_GH_PAT]` |
| Bearer / Auth Headers | `Bearer [a-zA-Z0-9_\-\.]{15,}` | `Bearer [REDACTED_AUTH_TOKEN]` |
| Private Cryptographic Keys | `-----BEGIN (RSA\|OPENSSH\|PRIVATE) KEY-----` | `[REDACTED_PRIVATE_KEY]` |
| Database Connection URIs | `(postgres\|mysql\|mongodb)://user:pass@host` | `protocol://[REDACTED_CREDENTIALS]@host` |
| JSON-Quoted Secret Fields | `"password": "...", "apiKey": "..."` | `"password": "[REDACTED]"` |

### 3.1 Excluded Sensitive Files
The Git engine (`lib/git.js`) explicitly excludes sensitive files from all diff notifications and file lists:
- `.env`, `.env.*`, `.env.local`
- `*.pem`, `*.key`, `*.p12`, `*.crt`
- `id_rsa`, `id_ed25519`, `known_hosts`
- `*.lfs`, `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`
- `.git-credentials`, `*.kdbx`, `kubeconfig`

## 4. Edge Storage & TTL Lifecycle

1. **Transient KV Queue**: Remote control commands (`/prompt`, `/run`, `/stop`, `/revert`) and interactive button responses are stored in Cloudflare KV with a strict **24-hour Time-to-Live (TTL)**.
2. **Immediate Consumption Deletion**: As soon as the local runner polls a queued action or an interactive button choice is processed, the record is immediately deleted from KV.
3. **No Database**: `agent-bell` does not employ any persistent SQL or NoSQL database. No user profiles, chat archives, or historical diffs are permanently stored.

## 5. Security & Authentication Architecture

- **Bearer Secret Authentication**: Local runner requests to Cloudflare Workers require a cryptographically secure `AUTH_SECRET` header.
- **Timing-Safe Equality**: Secret verification uses constant-time string comparison (`crypto.timingSafeEqual`) to prevent timing side-channel attacks.
- **Two-Way Webhook Verification**:
  - **Telegram**: Validates `X-Telegram-Bot-Api-Secret-Token` and whitelists authorized `chat_id`s.
  - **Discord**: Validates Ed25519 cryptographic signatures using native Web Crypto APIs.
  - **Slack**: Validates HMAC-SHA256 signatures with a 300-second replay attack protection window.
- **Process Jail & Path Safety**: Workspace directory changes strictly validate that paths resolve within user-approved workspace roots, completely preventing directory traversal attacks (`../../`).

## 6. Regulatory Compliance

### 6.1 GDPR (General Data Protection Regulation)
Because `agent-bell` does not collect, store, or process personal identifying information (PII) on any central server, the user acts as both the data controller and data processor of their own infrastructure. No cross-border personal data transfers occur outside of the user's chosen Cloudflare and notification providers.

### 6.2 CCPA (California Consumer Privacy Act)
`agent-bell` does not sell, share, or monetize any personal data.
